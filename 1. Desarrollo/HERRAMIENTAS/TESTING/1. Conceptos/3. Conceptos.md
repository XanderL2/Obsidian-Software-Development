## Conceptos:
- **Mocks:** Un Mock es una *simulacion de objetos que devolveria el backend*, esto se hace para probar nuestros datos de forma flexible. Por otro lado, nos sirve para que *los tests no dependan de la API*.
- **Fixture:** Es una clase de Angular que sirve para *crear instancias del componente* y acceder al *Objeto DOM nativo*.

	```ts
	describe('AppComponent', () => {
	  let fixture: ComponentFixture<AppComponent>;   // 👈 Permite acceder al objeto DOM del componente
	  let component: AppComponent; // 👈 Permite acceder a la clase del component
	
	  beforeEach(async () => {
	    await TestBed.configureTestingModule({
	      declarations: [AppComponent]
	    }).compileComponents();
	
	    fixture = TestBed.createComponent(AppComponent);
	    component = fixture.componentInstance;
	    fixture.detectChanges(); // inicia el binding y renderizado
	  });
	
	  it('should create the component', () => {
		// 👇 nos permite acceder a propiedades y metodos del componente 
		component.title; 
	    expect(component).toBeTruthy();
	  });
	
	  it('should render title', () => {
		// 👇 EL fixture nos permite acceder al DOM del componente
	    const compiled = fixture.nativeElement as HTMLElement; 
	    expect(compiled.querySelector('h1')?.textContent).toContain('Mi título');
	  });
	});

	```
