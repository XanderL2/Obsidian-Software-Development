## Estructura de un test en Angular:

```ts
describe('Nombre del grupo de pruebas', () => {
  beforeEach(() => {
    // Código que se ejecuta antes de cada test
	// Se usa para importar componentes, servicios o inicializar variables
  });

  it('debería hacer algo', () => {
    // Tu prueba va aquí
    expect(true).toBe(true);
  });
});
```

| Función      | Propósito                                                                  |
| ------------ | -------------------------------------------------------------------------- |
| `describe`   | Agrupa tests relacionados. Es como un "bloque de pruebas".                 |
| `it`         | Define un test individual.                                                 |
| `expect`     | Hace afirmaciones sobre valores.                                           |
| `beforeEach` | Código que se ejecuta **antes de cada test**. Ideal para instanciar datos. |
| `afterEach`  | Código que se ejecuta **después de cada test**. Limpia o resetea.          |

### Aserciones `{js icon} expects()`:

```ts
// Comparación de valores
expect(valor).toBe(esperado);               // Igualdad estricta (===)
expect(valor).not.toBe(esperado);           // Negación de igualdad estricta

expect(valor).toEqual(objeto);              // Comparación profunda (objetos/arrays)
expect(valor).not.toEqual(objeto);          // Negación de igualdad profunda

// Números y cantidades
expect(valor).toBeGreaterThan(n);           // valor > n
expect(valor).toBeGreaterThanOrEqual(n);    // valor >= n
expect(valor).toBeLessThan(n);              // valor < n
expect(valor).toBeLessThanOrEqual(n);       // valor <= n

// Cadenas y arrays
expect(cadena).toContain('texto');          // cadenas
expect(array).toContain(elemento);          // arrays

// Booleanos y null
expect(valor).toBeTruthy();                  // valor evaluado como true
expect(valor).toBeFalsy();                   // valor evaluado como false

expect(valor).toBeNull();                    // estrictamente null
expect(valor).toBeUndefined();               // estrictamente undefined
expect(valor).toBeDefined();                 // NO es undefined

// Errores y funciones
expect(funcion).toThrow();                   // lanza algún error
expect(funcion).toThrowError('mensaje');    // lanza error con mensaje

// Espías (spies)
const spy = spyOn(servicio, 'metodo');

expect(spy).toHaveBeenCalled();              // fue llamado
expect(spy).toHaveBeenCalledTimes(1);        // llamado n veces
expect(spy).toHaveBeenCalledWith(arg1, arg2);// llamado con argumentos
```


#### Ejemplo:

```ts
describe('AppComponent Tests', () => {

  beforeEach(async () => {
    await TestBed.configureTestingModule({
      imports: [AppComponent],
    }).compileComponents();
  });

  it('should create the app', () => {
    const fixture = TestBed.createComponent(AppComponent);
    const app = fixture.componentInstance;
    expect(app).toBeTruthy(); // 👈 Verifica que el valor es Truthy, osea el componente existe
  });

}
```
