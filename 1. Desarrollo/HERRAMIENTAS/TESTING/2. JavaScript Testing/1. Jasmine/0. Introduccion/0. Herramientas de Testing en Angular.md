## Herramientas por defecto para testing en Angular:

- ✅ **Jasmine:** Es el framework que usa por defecto Angular para escribir tests.  
- ✅ **Test Runner:** Karma es el encargado de correr los tests probandolos en un navegador real.
- ✅ **Test Bed:** Es el entorno que nos permite importar nuestros componentes en el test.


### Configuracion de Karma con Firefox:
- **Crear fichero de configuracion de Karma**
	```sh
	 ng generate config karma  
	```
- **Instalar el Launcher de Firefox para karma**
	```sh
	 npm install --save-dev karma-firefox-launcher
	```
- **Configuracion de `{js icon} karma.conf.js`:**

```js title:karma.conf.js
// Karma configuration file, see link for more information
// https://karma-runner.github.io/1.0/config/configuration-file.html

module.exports = function (config) {
  config.set({
    // Resto de configuracion...
    plugins: [
      require('karma-jasmine'),
      require('karma-chrome-launcher'),
      require('karma-firefox-launcher'), // 👈 Agregar esto
      require('karma-jasmine-html-reporter'),
      require('karma-coverage'),
      require('@angular-devkit/build-angular/plugins/karma')
    ],

	// Resto de configuracion...
    reporters: ['progress', 'kjhtml'],
    browsers: ['Chrome', 'Firefox'], // 👈 Agregar esto
    restartOnFileChange: true
  });
};
```
