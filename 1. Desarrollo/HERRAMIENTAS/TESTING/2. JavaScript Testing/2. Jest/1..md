

### Spys
- mockImplementation() => sirve para no llamar a la funcion real, se usa en spys.



### Metodos para funciones mock - jest fn()
- mockResolvedValue => sirve para simular la respuesta de valores asincronos.
- mockRejectedValue => sirve para simular la devolucion de una promesa con error.

### Expects:

- **Comprobar si un codigo asincrono (promesa) da error:**
	```ts
	await expect(getUser("2")).rejects.toThrow("User not found");
	```

- **Comprobar si una funcion lanza un error:**
	```ts
	expect(() => divide(10, 0)).toThrow("Cannot divide by zero");
	```
