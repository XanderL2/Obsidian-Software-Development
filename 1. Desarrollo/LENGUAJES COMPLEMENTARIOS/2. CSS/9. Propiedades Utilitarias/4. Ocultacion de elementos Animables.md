## Cosas a considerar para ocultar elementos:

- El `{css icon} display: none;` no es animable, por lo que existen formas **Alternativas** de animar las cosas.


### Propiedades usadas comunmente para animar:

| **Propiedad** | **Que hace?**               | **Oculta..**                                                         |
| ------------- | :-------------------------- | :------------------------------------------------------------------- |
| opacity       | Controla transparencia      | Sí, ocultas visualmente con fade                                     |
| max-height    | Limita altura máxima        | Si, si lo pones a 0 ocultas, si lo agrandas aparece verticalmente.   |
| max-width     | Limita el ancho maximo      | Si, si lo pones a 0 ocultas, si lo agrandas aparece horizontalmente. |
| scale: 0      | Escala tamaño visual (zoom) | Sí, ocultas escalando a 0, si lo agrandas a 1 aparece y es animable. |
### Ejemplo:

```css
.item{
    transition: all 0.4s;
}

.open {
    transition: opacity 0.5s ease, max-height 0.5s ease; 
	max-height: 100px;  // 👈 Solo senala la altura maxima, no la ocupa
}


.hidden {
    max-height: 0px; // 👈 Lo ocultamos poniendole la altura a 0
    overflow: hidden; // 👈 ocultamos el contenido que se desborde
    opacity: 0; // 👈 Hacemos que haga un fade de desaparicion
    transition: opacity 0.5s ease, max-height 0.5s ease; // 👈 Le agregamos transicion
}

```
