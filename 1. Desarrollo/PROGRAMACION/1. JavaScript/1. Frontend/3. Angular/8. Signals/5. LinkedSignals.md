### Que son las LinkedSignals:
- Es una especie de **Computed Signal**, pero que permite cambiar su valor.

### Ejemplo: 
- Cuando cambia la fuente de un linked signal, este recalcula nuevamente el en base a su declaracion.
```ts
const shippingOptions = signal(['Ground', 'Air', 'Sea']);

// linkedSignal que siempre apunta al primer elemento de shippingOptions
const selectedOption = linkedSignal(() => shippingOptions()[0]);
console.log(selectedOption()); // 'Ground'

// Cambiamos manualmente el valor de la linked signal
selectedOption.set(shippingOptions()[2]);
console.log(selectedOption()); // 'Sea'

// Cambiamos la fuente, el linkedSignal recalcula el valor (como se hizo en su declaracion)
shippingOptions.set(['Email', 'Will Call', 'Postal service']);
// 👇 Email
console.log(selectedOption()); // Selected opcion toma la posicion 0 en su declaracion, por eso devuelve email
```
