### Effects:
- Este solo se ejecutara **cuando el valor haya cambiado realmente**, no como el `{ts icon}tap()` que se ejecuta incluso si el valor no ha cambiado.
- Permiten ejecutar **Side Effects**.
- Se **ejecutaran al menos una vez**, producto de la inicializacion de las signals.
- El detecta automticamente cambios en las signals que estan dentro.
- Cada effect **debe tener una sola responsabilidad**.
- No se recomiendan para hacer peticiones HTTP.

```ts
@Injectable()
class HeroService {
	// 👇 Propiedad 
	private _characters = signal<Character>([{ name: 'kris', power: 1000 }]);

	// 👇 Cada que una signal cambie se ejecutara este efecto.
	public saveToLocalStorage = effect(() => {
		localStorage.setItem('characters', JSON.stringify(this._characters()));
	});

}
```
