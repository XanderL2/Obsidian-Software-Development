## Permite convertir cualquier observable a una Signal:
- Esta signal coge el ultimo valor emitido por el observable en forma de solo lectura.
- Devuelve un ReadOnlySignal

```ts
 const pairsSignal = toSignal(of(1, 2, 3, 4, 5).pipe(filter(n =>  n % 2 === 0)))
```


## Permite convertir un signal a un observable:
 - Convierte un Signal de Angular en un Observable de RxJS.
 - El Observable emite cada vez que el Signal cambia.

```ts
import { toObservable } from '@angular/core/rxjs-interop';
const myObservable$ = toObservable(mySignal);
```
