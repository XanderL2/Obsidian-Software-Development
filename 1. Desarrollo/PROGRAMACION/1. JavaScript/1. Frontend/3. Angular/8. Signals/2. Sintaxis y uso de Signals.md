## Elementos vitales de los Signals:
![[2. Sintaxis y uso de Signals 2025-06-30 16.21.28.excalidraw|900]]


### Writable Signals:
- **Creacion de Señales**
	```ts
	public counter = signal<number>(0);
	```

- **Acceder al valor de las señales:**
	```ts
	// 👇 Debemos usar los parentesis para acceder a las señales
	this.counter() 
	```

### Modificacion de Señales:
	
- **`{ts icon} update()`**
	```ts
	// Solo se debe usar cuando queremos modificarlo en base al valor anterior
	this.counter.update(currentValue => currentValue+ 1);
	```

- **`{ts icon} set()`**
	```ts
	// 👇 Solo queremos reemplazar directamente el valor
	this.counter.set(110);
	```


### Señales Computadas:
- Son calculos derivados de otras señales, es decir se actualizan automaticamente cuando las señales que operan cambian.
- Son de solo lectura

	```ts

	public product1 = signal<number>(10); // Esto puede cambiar de forma reactiva
  public product2 = signal<number>(5); // Esto puede cambiar de forma reactiva

  // 👇 Suma cambiara siempre cuando number1 o number2 cambien	
  public total = computed(() => this.product1() + this.product2()); 
	```

### Effects:
- Este solo se ejecutara **cuando el valor haya cambiado realmente**, no como el `{ts icon}tap()` que se ejecuta incluso si el valor no ha cambiado.
- Permiten ejecutar **Side Effects**.
- Se **ejecutaran al menos una vez**, producto de la inicializacion de las signals.
- El detecta automticamente cambios en las signals que estan dentro.

```ts
// Cada que cambie el tema se guardara en el localStorage
effect(() => {
	localStorage.setItem("theme", this.theme())
})
```
