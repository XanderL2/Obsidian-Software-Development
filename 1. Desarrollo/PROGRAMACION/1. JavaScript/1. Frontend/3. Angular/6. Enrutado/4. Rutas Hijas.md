## Para definir rutas hijas:
- Par definir rutas hijas usaremos el *Children*, este permitira tener rutas hijas.
- Cada `{html icon}<router-outlet/>` se llena con un componente correspondiente a su ruta.

### Ejemplo:
```ts
export const DASHBOARD_ROUTES: Routes = [
    {
        path: "dashboard",
        component: DashboardPageComponent,
        children: [
            {
                path: "customers",
                loadComponent: () => import("./customers/page/customers-page/customers-page.component"),
            },
            {
                path: "trending",
                loadComponent: () => import("./trending/page/trending-page/trending-page.component"),
            },
            {
                path: "search",
                loadComponent: () => import("./search/page/search-page/search-page.component"),
            },
			// 👇 Si ningun hijo coincide con las rutas
            {
                path: "**",
                redirectTo: "customers"
            }
        ]
    }
];

```
