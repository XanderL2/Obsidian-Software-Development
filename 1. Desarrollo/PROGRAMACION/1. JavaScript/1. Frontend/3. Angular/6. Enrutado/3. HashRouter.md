### Problema con el Router:
- **Rutas definidas en Angular** funcionan perfectamente en desarrollo (`ng serve`) porque el servidor de desarrollo sabe redirigir todas las solicitudes al `index.html`.
- En este caso le indicamos que la ruta `/` dirigira a Character Page, hasta aqui funcionara bien.
- Pero cuando queramos ir a `/counter` nos dara un error, porque no existe la carpeta `/counter` en el build que nos da Angular.

	```ts
	const routes: Routes = [
	  {
	    component: CharacterPage,
	    path: '' 
	  },
	  {
	    component: CounterPageComponent,
	    path: 'counter'
	  },
	  {
	    path: '**',
	    component: CharacterPage
	  }
	];
	```

### Para solucionar el problema:
Debemos que hacer que todas las rutas en vez de pasar como si fueran directorios, **pasen como rutas Angular**, **es decir pasen por el `{html icon} index.html`** antes. Entonces tenemos 2 opciones.

- *Opcion 1:  Configurar Angular para que se encargue de este problema.*
	- Alternativa que **evita tocar la configuración del servidor**, por ende mas aplicable a hostings como *github pages*.
	- Cambia la URL a algo como `/#/counter`, así el servidor siempre ve `/` y Angular maneja el resto.
	- Esta opcion tiene problemas con CEO ❗.
	```ts
	import { LocationStrategy, HashLocationStrategy } from '@angular/common';
	
	@NgModule({
	  providers: [{ provide: LocationStrategy, useClass: HashLocationStrategy }]
	})
	export class AppModule {}
	```
- *Opcion 2 (Mejor allternativa si se tiene acceso al servidor):* 
	- Configurar el servidor para que todas las rutas pasen por el index.html.
	```nginx
	location / {
	  try_files $uri /index.html;
	}
		
	```
