## En frameworks Reactivos como Angular, React, etc:
1. Haces la petición a la API (fetch, axios, http client, etc.)
2. Esto devuelve una promesa o un observable.
3. Mientras esperas la respuesta, actualizas el estado a "loading" Por ejemplo, en un store, un state local, o un contexto.
4. Cuando recibes la respuesta con éxito, como SideEffect actualizas el estado con los datos y pones "success". Esto hace que la UI se renderice con los datos.
5. Si hay error, capturas ese error y actualizas el estado con "error" y la info del error. De esa manera se pueden mostrar mensajes de errores especificos en componentes en concreto.
