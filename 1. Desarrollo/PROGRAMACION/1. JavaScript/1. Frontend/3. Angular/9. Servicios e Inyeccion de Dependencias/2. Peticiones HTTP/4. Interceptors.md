## Que son los interceptors:
- Son estructuras que interceptan cada solicitud http que se hace con el HttpClient.
- Esta nos puede servir para:
	- Agregar un token en los headers.
	- Manejar errores globalmente y no tener que manejarlos en cada peticion.
	- Agregar loaders globales (No especificos).
	- Mostar toasts (Mensajes de error globales).

### Ejemplo:
```ts
import { HttpErrorResponse, HttpInterceptorFn } from '@angular/common/http';
import { catchError, throwError } from 'rxjs';


export const loadingInterceptor: HttpInterceptorFn = (req, next) => {

  // Aqui se pondria un loader
  const token = localStorage.getItem('token');

  if (token) {
    const newRequest = req.clone({
      setHeaders: {
        Authorization: `Bearer ${token}`
      }
    });
  } 

  return next(req).pipe(
    catchError((err: HttpErrorResponse) => {

      // Mostrar un pop-up de error, o un mensaje de error en la UI
      return throwError(() => err.error.message); // Propagar error al componente que hace el subscribe
    })
  );
};
```

### Usar los interceptors en cada peticion:

```ts title:app.config.ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideZoneChangeDetection({ eventCoalescing: true }), 
    provideRouter(routes),
    provideHttpClient(withInterceptors(
      [loadingInterceptor] // 👈 Aqui usarimos nuestros interceptors
    ))

  ]
};
```
