## Que es ViewModelObservable?
-  Es un `{ts icon} Observable()` que emite objetos con toda la informacion que la vista necesita. 
- *Ejemplo:*
	- Esta forma permite no tener variables regadas por cada componente.
	```ts
	interface ViewModel {
	  data: Student[];
	  loading: boolean;
	  error: string | null;
	}
	```

### Ventajas:
- *Menos variables regadas por componentes*
- *Codigo mas limpio*
- *Mas facil de manejar*
- *Menos verboso*

### Deventajas:
- *Puede ser mas complejo si no se esta familiiarizado con RxJS*

---

>💡 **Este patrón obliga a realizar una suscripción dentro del servicio, y eso está bien.**  
Solo debemos suscribirnos en el servicio **cuando vamos a manejar un estado interno** (por ejemplo, con `{ts icon}BehaviorSubject`).  
Por otro lado, **si no vamos a manejar estado y solo queremos devolver la información**, es mejor simplemente **retornar el observable** y dejar que el componente se suscriba.
### ViewModel Escalable:

- *ViewModel Estricto*
	```ts
	export interface ViewModel<T> {
	  data: T;
	  loading: boolean;
	  error: string | null;
	}
	```
