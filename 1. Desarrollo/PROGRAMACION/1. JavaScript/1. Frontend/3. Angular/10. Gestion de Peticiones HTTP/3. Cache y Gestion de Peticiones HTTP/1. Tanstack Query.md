## *Que es Tanstack Query?*
- Es una herramienta que permite *gestionar el estado de datos que provienen de peticiones asincronas (Http por ejemplo)*.
- Este permitiria *ahorrar todo el patron clasico de angular* de guardar los datos en un signal, compartirlo y tenerlo actualizado, ya que el se *encargaria de compartir los datos a traves de su cache reactivo*.
- Permite manejar el estado de *loading, error y success* de forma eficiente y rapida. 
- Agregado a esto, permite tambien *gestionar errores y reintentar peticiones*, ademas de proveer diversas *estrategias de actualizacion de cache*.

--- 

>💡 *Regla de Oro:* Si un service existe solo para guardar datos del backend → elimínalo y usa TanStack Query.

---
### *Estados del cache de Tanstack Query:*

> 💡 *Stale Time:* Es el tiempo en el que los datos se consideran “frescos” y no se vuelven a pedir al servidor.

- **Fetching:** La query está realizando la peticion, ya sea por primera vez o refrescando.
- **Fresh:** Los datos están “frescos”, es decir, acaban de ser obtenidos o aún no ha pasado el tiempo de staleTime.
- **Stale:** Los datos estan obsoletos y se intentara refrescar los datos segun lo que le hayamos dado en la configuracion.
- **Paused:** La query está esperando para hacer la petición, normalmente porque no hay conexión a internet o la app está en segundo plano.
- **Paused:** No hay ningún componente usando la query en ese momento, pero los datos siguen en caché.
