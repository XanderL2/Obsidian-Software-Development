### Que son las mutaciones?
- Las mutaciones son operaciones para *crear, editar o actualizar datos en el servidor*. 
- Normalmente, luego de ejecutar la mutacion se invalida la query.
### Ejemplo:

> **Que significa invalidar las queries:**
> Significa, que tanstack marca como *Stale*, esperando a que algun componente que este usando la query se renderice para ejecutar la peticion

```ts title:ProductStore
@Injectable({
  providedIn: 'root',
})
export class ProductStore {

	addNewStudent() {
	  return injectMutation(() => ({
	    mutationFn: (newStudentData: any) => this.studentApiClient.createNewStudent(newStudentData),
		// 👇 Eso es opcional
	    onSuccess: () => {
	      this.queryClient.invalidateQueries({ queryKey: ['students'] });
	    }
	  }));
	}

}
```

#### Uso en el componente:

```ts title:Component
@Component({
  selector: 'app-student-form',
  templateUrl: './student-form.component.html',
})
export class StudentFormComponent {

  // 1 - Inyectas el store
  private productStore = inject(ProductStore);

  // 2 - Obtienes la mutación
  addStudentMutation = this.productStore.addNewStudent();

  // 3 - Ejecutas la mutacion 
  async submit() {
    const newStudent = {
      name: 'Juan',
      age: 20,
    };
	
	try {
		const res = this.addStudentMutation.mutateAsync(newStudent);
		console.log(res);
	} catch(error) {
		console.error(errror)	
	}
    
  }
}
```
