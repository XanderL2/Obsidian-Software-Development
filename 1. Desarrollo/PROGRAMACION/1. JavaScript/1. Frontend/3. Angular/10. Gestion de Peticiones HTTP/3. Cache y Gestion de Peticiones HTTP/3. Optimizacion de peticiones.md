## Que es la optimizacion de Peticiones?
- Es un proceso que permite que nuestra aplicacion use diversas estrategias para ofrecer una buena *experiencia de usuario*, estas van desde *hacer un prefetch* *hasta coger partes de otra peticion para evitar hacer una nueva*.


### Prefetch (Adelantarse a la seleccion del user): 
- El prefetch query, lo que hace es *empezar a realizar la peticion desde antes*, para que cuando los pidas con un *injectQuery ya esten cargados*

> - 💡 *Recomendaciones para le buen uso:*
> 	- Haz prefetch solo de *los datos que probablemente necesitará el usuario* (por ejemplo, la siguiente página, o detalles de un producto al hacer hover).  	
> 	- Ajusta el *stale time* para que el caché dure lo suficiente y evite peticiones innecesarias.

```ts title:Ejemplo
@Injectable({
  providedIn: 'root',
})
export class ProductStore {

  private readonly _productApiClient = inject(ProductApiClient);
  private readonly _queryClient = inject(QueryClient);
 
  private productDetailStaleTime = 1000 * 60 * 5; 

  prefetchProductDetail(id: string) {
    this._queryClient.prefetchQuery({
	  // 👇 Debe ser la misma query KEY del injectQuery original
      queryKey: ['product', id], 
	  // 👇 Debe ser la funcion del injectQuery original
      queryFn: () => this._productApiClient.getProductDetail(id)
	  
	  // 👇 El stale time debe ser el mismo que el del injectQuery original
	  staleTime: this.productDetailStaleTime
    })
  } 

}
```
