## RxResource

- Permite realizar peticiones **HTTP directamente desde observables** controlando los estados de las peticiones HTTP de forma automatica.
- Ademas, permite definir en el **Request** parametros, que si cambian se volvera a hacer la peticion, como un **Effect**.
- Solo es usable para peticiones **GET**, por esto se ejecutan apenas se inicializa el componente.
- Internamente provee un estado que puede ser alterado de manera local en el componente.
### Uso: 

```ts
  productsResource = rxResource({
	// Parametros que pueden cambiar
    params: () => ({ category: this.category() }),
	
	// Observable que dispara la peticion: 
    stream: ({ params }) => {
      console.log(params)
      return this.api.getProducts(1);
    } 
  });
```

### Estados y Utilidades:

```html
<section class="w-full p-5 flex flex-center justify-center">
    <!-- Si el recurso tiene un valor -->
    @if (productsResource.hasValue()) {
        <app-product-list [products]="productsResource.value()"></app-product-list>
    }
    <!-- Si el recurso está cargando -->
    @else if (productsResource.isLoading()) {
        <app-loader></app-loader>
    }
    <!-- Si el recurso tiene un error -->
    @else if (productsResource.error()) {
        <p>errorc:</p>
    }
</section>
```
