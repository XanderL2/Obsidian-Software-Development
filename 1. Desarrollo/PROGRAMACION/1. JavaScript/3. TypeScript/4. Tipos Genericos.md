## Genericos

- **Clases genericas**
	```ts
	class Storage<T> {
	  private items: T[] = [];
	
	  add(item: T): void {
	    this.items.push(item);
	  }
	
	  getAll(): T[] {
	    return this.items;
	  }
	}
	```

- **Clases normales con metodos genericos**
	```ts
	class Utils {
	  // Método genérico
	  identity<T>(value: T): T {
	    return value;
	  }
	
	  // Otro método genérico
	  wrapInArray<T>(value: T): T[] {
	    return [value];
	  }
	}
	```
