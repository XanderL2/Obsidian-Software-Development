## Flexibilidad en tipos de datos: 

- **Union Types:**
	- Permite decir que el array puede tener valores de 2 tipos en concreto.
```ts
// Indica que elements podra tener strings y numeros
let elements: (string | number)[] =  ["kris", 69];
```

- **Union Type Condicional**
	- Permite indicar que el array puede ser 2 tipos en concreto (un array de string o de numbers)
```ts
let elements: string[] | number[] =  [];
```
- **Pick**
	- Permite indicar un nuevo tipo eligiendo las propiedades necesarias.
```ts
let elements: string[] | number[] =  [];
```
- **Partial**
	-  Hace todas las propiedades opcionales.
```ts
function updateUser(user: User, updates: Partial<User>) {
  return { ...user, ...updates };
}
```
