### Reemplazo del Switch (Map):
- Es como un objeto (Pares clave valor), pero en el que las claves pueden ser de distinto tipo.

	```js
	const mapa = new Map();
	
	mapa.set('nombre', 'Juan');
	mapa.set(42, 'respuesta');
	mapa.set(true, 'sí');
	
	console.log(mapa.get(42)); // "respuesta"
	console.log(mapa.size);    // 3
	```

### Pasar distintos parametros:
```js
function miFuncion(...args: number[]) {
  args.forEach(arg => console.log(arg));
}

miFuncion(1, 2, 3, 4);
```
